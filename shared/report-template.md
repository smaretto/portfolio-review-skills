# Report template

Produce the report in this structure. Use the competency list and level
definitions from the skill's own references. Keep it readable: tables where
the content is a comparison, short prose elsewhere. Aim for a report a
hiring manager can read in five minutes, with detail available below.

```markdown
# Portfolio review: [name or "Anonymous"], [target role or level]

## Inputs
- Source: [URL or file]
- Read: [case studies or pages read]; skipped: [list and reason, or "none"]
- Visual assessment: [full / partial / none, and why]
- Context supplied: [target level, JD yes/no, mode, intended image yes/no]
- Reviewer perspective: [this skill's perspective]

## Verdict
**[Exceptional / Strong hire / Hireable / Unsure / No hire]** for [target].
[Two sentences: why, and the main thing holding it back.]
Caps applied: [list, or "none"]

## What this portfolio says about this person
[Three to five plain sentences. The read a hiring manager would give a
colleague.]

## Level and scope read
- Target: [level]
- Portfolio reads as: [level], confidence [high / medium / low]
- Title claimed: [title], scope shown: [scope summary]
- Evidence: [the scope signals that drove the read]

## Competency evidence
| Competency | Rating | Evidence strength | Evidence (where) |
| --- | --- | --- | --- |
| ... | At level | Demonstrated | [paraphrase, case study / page] |

Low-confidence ratings: [list and why, or "none"]

## Profile shape and archetype
[Archetype from the skill's levels file. Strongest and weakest areas. What
the shape suggests.]

## Distinctive signals
[Zero to three signals, each with evidence and why it is uncommon. Or "No
clear differentiator", stated plainly.]

## Market placement
- Best fit: ...
- Weak fit: ...
- Competitive position: ...

## Portfolio effectiveness
| Dimension | Rating | Note |
| --- | --- | --- |
| Positioning and niche | | |
| Case selection | | |
| Storytelling | | |
| Visual evidence | | |
| Readability | | |
| Hygiene | | |

Skim-pass impression vs deep-pass impression: [one or two lines]
Single most valuable change: [one line]

## Red flags
| Severity | Flag | Evidence |
| --- | --- | --- |
[Or "None found".]

## Fit against the role  (conditional: JD or requirements supplied)
| Requirement | Evidence | Status (met / partial / not shown) |
| --- | --- | --- |

## Intended vs perceived  (conditional: self-assessment mode)
| What you want it to say | What it says | Status | Fix |
| --- | --- | --- | --- |
Status values: Supported / Partly supported / Not supported / Contradicted.

## Next steps
[Reviewer mode: three to six interview questions that would resolve the
biggest uncertainties, each tied to a gap above.]
[Self-assessment mode: three to six fixes in priority order, each concrete
enough to act on this week, each tied to a finding above.]
```
