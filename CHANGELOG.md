# Changelog

## 0.2.0 (2026-10-23)

Changes from the first test run on a real Director-level portfolio.

Shared
- reading-inputs: new "Verifying what you read" section. Fetch summaries
  can misreport; collapsed content must be read; alt text is not content;
  unrendered images are "not seen", not missing; cross-check numbers across
  pages.
- evidence-rules: inconsistent figures use the conservative value and are
  noted.
- portfolio-effectiveness: hidden narrative (accordions, tabs) and machine
  readability (alt text, text inside images) added.

Both skills
- Ambiguous authorship defaults to reviewer mode with an offer to rerun as
  self-assessment.
- Verification step before rating; checklist item for it.

Leadership skill
- levels: leadership through senior ICs and managers in development added
  as scope signals; VP titles at small companies mapped by scope.
- competencies: Director People Development credits developing leads and
  staff ICs who carry coaching and delivery responsibility.
